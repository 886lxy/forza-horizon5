# Forza Horizon 5 · 极限竞速：地平线 5

一个基于 Three.js (r180) 与 WebGL2 的单文件 3D 交互展示页，主题为「国际赛车场与专业试驾训练中心」。

## 在线体验

https://886lxy.github.io/forza-horizon5/

## 特性

- 纯单文件 `index.html`，无构建步骤、无本地依赖安装
- Three.js r180 + WebGL2 渲染的 3D 赛车场景
- 响应式布局，桌面与移动端均可访问
- 托管于 GitHub Pages，推送即自动发布

## 本地运行

直接双击 `index.html`，或在目录内启动任意静态服务器：

```bash
python -m http.server 8000
```

然后访问 http://localhost:8000
